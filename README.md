## ✨ Features
- 🎯 60+ questions across OOP, Java, DSA, DBMS, OS, CN, Math, CS
- 🎲 Random questions every game with randomized answer positions
- ⏱️ Timer per question (varies by difficulty)
- 🔥 Streak system with bonus points
- 💡 Lifelines: 50/50 and Hint (one each per game)
- 🏆 Grade system S+ to F
- 🏅 Achievement badges
- 💾 High score saved locally
- 📱 Fully mobile responsive
- 🔊 Web Audio sound effects
